    How are the scores calculated?

    False color is the average gap between the largest and smallest RGB channel values. The original is grayscale, so the ideal gap is zero. Brightness error is the root mean square difference between the reconstructed mean RGB value and the original gray value. Lower is better for both scores. The calculation skips the two-pixel border, where both methods use the same reconstruction.
