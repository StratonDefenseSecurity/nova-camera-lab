# Two-minute visitor test

**Status** — ready to run with five first-time visitors. The table records observations after the sessions.

## How to run each session

1. Open the lab in a fresh tab at its starting state. Reuse the same version for all participants. Hand over the device and give the same neutral instruction each time: “Please explore this page for up to two minutes. I’m testing the page, so use it however you like.” Start timing when the page is visible.
2. Watch without coaching. Note the first action, when the visitor reaches the sensor reading, whether they finish building the pixel, and where they hesitate. End the observation at two minutes even if they are still exploring.
3. Show a different gray fine pattern, such as a real piece of mesh or a printed grid. Use the physical object or its original grayscale view, with the lab feedback out of view. Ask: “Imagine a photo of this pattern has purple streaks, while the object is gray. Where could the color have come from? What could you change to test your explanation?” Let them answer before revealing the controls.
4. Record the answer in your own notes with a participant code. Use no names or recordings. The questions may be asked in the participant’s preferred language. Report the language and device alongside the observation so the team can interpret it.

## Scoring the explanation

- **2** — independently explains that each sensor point measured only one color channel and that the reconstruction estimated the missing channels, which could produce the false color.
- **1** — mentions that the camera or software could have added the color, with the measurement and estimation distinction still unclear.
- **0** — offers an unrelated explanation or says they are unsure.

Record the transfer answer separately. Mark **Yes** if the visitor proposes a relevant test, such as changing angle or distance and checking whether the artifact changes. Write down their wording for ambiguous cases before assigning a score.
